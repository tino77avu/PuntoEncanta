# Imágenes para el sitio Netlify

Coloca en esta carpeta:

- **`Logo.png`** – Logo del sitio (header y favicon).
- **`Inicio.png`** – Imagen de fondo del hero en la página de inicio.

Sin estos archivos el sitio seguirá funcionando, pero no se verá el logo ni el fondo del hero.

Origen de los archivos (si ya los tienes en el proyecto Spring Boot):
`src/main/resources/static/images/Logo.png` y `Inicio.png`.
